# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-16

### Added

- Interactive presentation with project flow, converter mockup, and three-stage comparison.
- Lazy-loaded Excalidraw viewer with zoom, pan, fit-to-screen, and an equivalent textual description.
- AI-assisted document review mockup with structure, source preview, suggestions, and EPUB export flow.
- Embedded comparison of the scanned page, Mathpix Markdown, and reconstructed EPUB.
- Responsive modal presentation for desktop and mobile layouts.
- Accessibility audit, deployment guide, contribution guide, and third-party attribution.

### Changed

- Standardized event naming to OrionHub 2026, OrionStar 2026, and Laboratório Orion.
- Identified the source excerpt as *Pré-cálculo*, by Francisco Magalhães Gomes.
- Simplified the visual language and aligned the comparison and mockup with the main design system.

### Fixed

- Corrected keyboard focus, modal isolation, reflow, control sizing, contrast, and reduced-motion behavior.
- Corrected EPUB source metadata and removed the temporary conformance and certification claim.
- Corrected mobile figure visibility and added a dedicated enlarged preview.
